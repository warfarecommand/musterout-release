# Muster Out releases

This public repository holds the files for installing and updating Muster Out in a regular Claude chat. It contains release files; development takes place separately.

Read the [setup instructions](SETUP.md) to start.

For notices, send: "Run the Muster Out weekly check. Read https://raw.githubusercontent.com/warfarecommand/musterout-release/main/WEEKLY.md and follow it."

For a new release, send: "Update Muster Out. Read https://raw.githubusercontent.com/warfarecommand/musterout-release/main/UPDATE.md and follow it." The board shows both under Talk to Claude.

[Visit Muster Out](https://musterout.warfarecommand.com) for coverage and setup. The laptop setup is available there as an alternative.
