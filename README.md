# Muster Out releases

This public repository holds the files for installing and updating Muster Out in a regular Claude chat. It contains release files; development takes place separately.

Read the [setup instructions](SETUP.md) to start. The [weekly check](WEEKLY.md) reviews MARADMIN notices. The [update instructions](UPDATE.md) keep the existing board address and data.

[Visit Muster Out](https://musterout.warfarecommand.com) for coverage and setup. The laptop folder is available there as an alternative.
