## Add your coach after your board opens

Tap counts are planning estimates from DESIGN.md, not verified button labels. Typing and switching apps are not counted. Project controls vary by device. Android setup and Project publishing are not yet tested.

1. On the welcome page, tap **Copy coach setup**. 1 tap. If Copy fails, press and hold the block, Select All, then Copy.
2. Open the Claude app, open the left menu, tap **Projects**, **+**, name it **Muster Out**, and tap **Create**. About 4 taps plus typing. If creation is missing, use claude.ai/projects in a browser or Set up or resume your board below.
3. Open **Add instructions**, paste the block below, and save. About 3 taps. Reopen it to check the full block saved. If the field rejects it, use the browser Project instructions; otherwise use Set up or resume your board.
4. Start a new chat inside the Project and send **Read my existing board**. Provide your board link; Claude checks only that selected board. A failed read is not a missing board. Never publish a second board to recover. After the coach reads your plan, ask for this week's priorities. Any offer to save facts or schedule a check in requires your separate approval.

Keep the same board if any step fails. Reopen it directly and use a regular Claude chat while you finish Project setup. A tool error must never create a second board.
